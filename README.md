# New Dimensions

A deliberately quiet, node-by-node mind-mapping laboratory.

The landing screen contains only:

- six separate dimensional buttons, **1D–6D**;
- one **Just map** button;
- one **Start now.** button that remains inactive until a mode is chosen.

## Interaction

1. Choose one mode.
2. Press **Start now.**
3. Tap or click anywhere on the blank canvas and name the first thought.
4. Only the active thought displays coaching options.
5. Select one open question, then tap empty space to add a new thought or tap an existing thought to connect it.
6. Continue one thought and one relationship at a time.

The coaching never supplies answers or pre-builds a structure. It asks changing, open questions. Tapping the active thought again, or using the refresh control, reveals a different set.

The number of visible questions is intentionally proportional to the chosen mode:

| Mode | Immediate reasoning field |
|---|---|
| 1D | One linear/focal question at a time |
| 2D | Two direct relational questions |
| 3D | Three system-interaction questions |
| 4D | Four transformation/time/feedback questions |
| 5D | Five trajectory and counterfactual questions |
| 6D | Six generative-rule and possibility-space questions |
| Just map | No dimensional curriculum; free nodes and optional labelled connections |

Every dimensional mode has a larger rotating question bank, so the displayed questions change with the active thought, map size, prior questions and refresh cycle. **Own connection** always remains available, preserving exploration rather than forcing the learner through a predetermined syllabus.

## Controls

- Tap a thought to continue from it.
- Tap the selected thought again to rotate its questions.
- Drag a thought to reposition it.
- Drag empty space to pan.
- Pinch or use the mouse wheel to zoom.
- While a question is active, tap an existing thought to create a cross-link or feedback loop.
- Double-click a thought, or use the top-right menu, to rename it.
- Click a relationship label to revise or delete the line.
- Work is saved locally in the browser without adding library screens or other landing-page noise.

## Validate locally

```bash
node --check app.js
node --check reasoning.js
node --test tests.mjs
python3 -m http.server 8080
```

The “dimension” labels are a designed teaching grammar for increasingly complex reasoning operations. They are not a claim about literal spatial dimensions or a psychometric scale.
